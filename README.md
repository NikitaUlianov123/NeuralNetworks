# NeuralNetworks

Machine learning and game AI experiments in C#, written from scratch without ML libraries (2022 to 2024).

## What's here

- **NeuralNetworks/Perceptron**: a single perceptron, with pluggable activation and error functions.
- **NeuralNetworks/NeuralNetwork** and **NeuralNetwork2**: multi-layer neural networks. `NeuralNetwork2` trains with backpropagation, momentum and mini-batches.
- **NeuralNetworks/Flappy** and **NetworkTester**: a Flappy Bird clone (MonoGame) and a WinForms version, where a population of networks learns to play through a genetic algorithm.
- **NeuralNetworks/HillClimber** and **HillClimber2**: hill climbing, from matching a target string to a visual WinForms version.
- **Genetic art**: a genetic algorithm that approximates an image with a set of triangles.
- **GameTheory**: minimax on tic-tac-toe.
- **MonteCarlo**: Monte Carlo search on tic-tac-toe and checkers.
